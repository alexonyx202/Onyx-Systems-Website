## Post 4 — PRACTICAL/SHOP

**Headline:** Deleted a File by Mistake? Recuva Recovers It Free — No Tech Skills Needed

**The Tip:** Recuva (ccleaner.com/recuva) is the free Windows tool that recovers deleted photos, documents, and files from hard drives, USB sticks, and memory cards. Works on Windows 10 and 11

**The Shop Owner's Truth:** People panic and keep using the drive — that overwrites the deleted data and makes recovery impossible. Stop using the drive the second you realize a file is gone.

**What I Actually Do:** I run Recuva in "Deep Scan" mode from a USB stick so I don't write to the customer's drive. For SSDs with TRIM, recovery is hit-or-miss — that's why I push OneDrive backup (Post 5) harder than any recovery tool.

**The Onyx Promise:** If you've lost something important, bring it in before you try anything else. We'll give you the honest odds.

## Post 5 — SOFTWARE/BROWSER

**Headline:** Windows Quick Assist Gives Free Remote Help — No Third-Party Tool Needed

**The Tip:** Windows Quick Assist (built into Windows 10 and 11) lets someone you trust see your screen and help fix problems. Open Start, search Quick Assist, click "Help someone" and share the code. Free, no install

**The Shop Owner's Truth:** I've seen people pay $100+ for "remote support" scams when Windows has had this built in since 2016. The scammer asks you to install TeamViewer or AnyDesk — Quick Assist needs zero downloads.

**What I Actually Do:** When a customer calls stuck on something simple, I walk them through Quick Assist over the phone. They share the 6-digit code, I connect, fix it in two minutes, and they learn where the tool lives for next time.

**The Onyx Promise:** We'll never ask you to install remote software you don't need. If we connect, it's through tools you already have.
