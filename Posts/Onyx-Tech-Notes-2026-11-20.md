## Post 2

**Headline:** Windows 11 has free ransomware protection built in — turn on Controlled Folder Access in Windows Security

**The Tip:** Open Windows Security (press Start and type "Windows Security"). Click Virus & threat protection, then Manage ransomware protection. Turn on Controlled folder access. It protects Documents, Pictures, and Desktop folders automatically. Free, no install needed.

**The Shop Owner's Truth:** Most people pay for third-party "ransomware protection" that does less than the free switch Microsoft already built in. I turn this on for every customer before they leave the shop.

**What I Actually Do:** Windows Security → Virus & threat protection → Manage ransomware protection → toggle Controlled folder access ON. Add custom folders via "Protected folders" if needed. Allow trusted apps via "Allow an app through Controlled folder access" when something legitimate gets blocked.

## Post 3

**Headline:** Windows 11 November update fixes USB headphone and HDMI audio glitches — free update via Windows Update

**The Tip:** KB5132061 (released November 10) fixes audio dropouts on USB Audio 1.0 devices (many headsets and DACs) and AMD HDMI/DisplayPort audio on supported PCs. Open Settings > Windows Update and click Check for updates. Restart after installing.

**The Shop Owner's Truth:** Audio problems are the number one "my computer is broken" call that turns out to be a driver or update issue. This update fixes a whole class of them for free.

**What I Actually Do:** Settings → Windows Update → Check for updates → install KB5132061 → restart. For stubborn audio issues after updating: Settings → System → Sound → choose the correct output device → run the "Test" button.

## Post 5

**Headline:** Windows 11 November update adds Cloud Rebuild — reinstall Windows without a USB drive via Settings > System > Recovery

**The Tip:** KB5132061 (released November 10) brings Cloud Rebuild to supported Windows 11 PCs. If Windows won't start, the recovery environment downloads a fresh Windows and drivers from Microsoft — no USB stick needed. Go to Settings > System > Recovery > Reinstall now. Back up your files first — Cloud Rebuild removes everything.

**The Shop Owner's Truth:** Half the "dead" laptops I see just need a clean Windows install. Cloud Rebuild means you don't need a second computer, an 8 GB USB stick, and 30 minutes of fuss to make one. It's built in.

**What I Actually Do:** Settings → System → Recovery → "Reinstall now" (under "Reset this PC"). Choose "Cloud download" (not "Local reinstall"). It pulls a fresh Windows image from Microsoft. Takes 20–40 minutes on decent internet. All apps and files gone — back up first.
