## Post 2

**Headline:** Windows 11 November 2026 update brings Hotpatch security updates and Cloud Rebuild free

**The Tip:** The November 2026 update (KB5132061) for Windows 11 24H2, 25H2, and 26H2 includes Hotpatch support — security updates that install without a restart — and Cloud Rebuild, which lets you reinstall Windows from the cloud without a USB drive. Get it now: open Settings > Windows Update and click Check for updates.

**The Shop Owner's Truth:** Most people delay updates because they hate restarts. Hotpatch changes that equation — security fixes apply silently in the background. This is the first time Windows has had true restartless patching for consumers, and it's a bigger deal than the marketing lets on.

**What I Actually Do:** On every shop machine, I enable "Get the latest updates as soon as they're available" in Settings > Windows Update > Advanced options. Then I run `winget upgrade --all` to catch third-party apps Windows Update misses.

**The Onyx Promise:** We'll make sure your updates actually install — not just download and wait. Bring it in if Windows Update gets stuck.

## Post 3

**Headline:** Firefox 160 Mini Window pops any tab into an always-on-top overlay for multitasking free

**The Tip:** Firefox 160 (released November 10) adds Mini Window — right-click any tab and choose Open in Mini Window to keep a video, document, or page visible while you work in other apps. Also new: Picture-in-Picture playback speed controls (0.25x–2x), a "Never Allow" button to stop sites from pestering you to handle email links, and on-device speech recognition in 40 languages. Update free at firefox.com or Menu > Help > About Firefox.

**The Shop Owner's Truth:** Mini Window is the feature I didn't know I needed until I used it — keeping a YouTube tutorial or reference doc floating over my workspace beats alt-tabbing constantly. It's still early (Mozilla calls it a "beta" feature), but it already feels essential.

**What I Actually Do:** I set Firefox as the default browser on every customer machine and enable "Delete cookies and site data when you close all windows" in Settings > Privacy & Security. For shop machines, I also deploy the Firefox Enterprise ESR (currently 153.7) for stability.

**The Onyx Promise:** If Firefox breaks a site you need, we'll fix the profile or find the setting — no "switch to Chrome" pressure.
