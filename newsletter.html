🔴 ALERT

A critical **Metabase SQL injection zero-day** (CVSS 10.0) is being actively exploited right now. Attackers hit Metabase Cloud and self-hosted instances (versions 1.58+) — stealing customer data from Framework, Tally, and others. The flaw lets unauthenticated remote attackers gain admin access, steal database credentials, and export all connected data. If you run Metabase, **upgrade immediately** to patched versions (0.58.24, 0.59.21, 0.60.17, 0.61.11, 0.62.9, 0.63.5 or newer). Can't upgrade yet? Block access to `/api/session/reset_password` endpoint. Check logs for POST to that endpoint returning 400 followed by successful GET to `/api/user/current` — that's the attack signature. *Source: BleepingComputer — August 7, 2026; Metabase Security Advisory GHSA-vwf4-m7j8-wcjf*

Daily Tip

Accidentally closed a tab? Press **Ctrl+Shift+T** (Windows) or **Cmd+Shift+T** (Mac) to reopen it instantly. Works in Chrome, Edge, Firefox, and Safari. Repeat to reopen multiple tabs in reverse order. Takes one second — saves the frustration of digging through history.
