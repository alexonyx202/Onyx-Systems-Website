# Onyx Systems — Website

Static site for **Onyx Systems | Computer Care Center**, Lake City, FL.
Single-file `index.html` (no build step). Hosted on GitHub Pages at
`https://onyxpc.us` (custom domain).

## Deploy
The repo is published via GitHub Pages from the `main` branch root.
The `CNAME` file binds the custom domain `onyxpc.us`.

## Local preview
```bash
python3 -m http.server 8000
# open http://localhost:8000
```
