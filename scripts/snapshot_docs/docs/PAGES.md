# Pages

Four core pages at the root plus the arcade hub under `games/` and 22 game
pages. Every core page carries the `onyx-build` stamp meta tag and the
service worker (`sw.js`).

## `games/index.html` — arcade hub

- Renders **19 game cards** from `games/games.json` (title, tagline,
  description, thumbnail, cabinet image).
- Card taps **navigate to the game in the same tab**.
- **Mobile tap fix (2026-08-26)**: the old click handler called
  `e.preventDefault()` on every tap in `(hover:none)` media, which
  cancelled the `<a href>` navigation on phones/tablets — cards did
  nothing when tapped. Fixed by removing `preventDefault()` and adding the
  `[MOBILE FIX 2026-07-19]` comment (the same fix the homepage received
  on 2026-07-19). The QA verifier has a behavioral guard for this.
- Embeds the inline fallback manifest (kept in sync with `games.json` by
  `scripts/regenerate_manifest.py`).
- Games open with the same service-worker freshness layer.

## `crossword.html` — daily crossword

- Loads today's puzzle from `data/today_crossword.json` (via
  `crossword.js`); 24×24 grid on 2026-08-26.
- **Board sizing fix (2026-08-26)**: `.xw-board` now has a definite
  `height: min(58vh, 520px)` so `fitCell()` computes a real cell size.
  Previously the mobile layout gave the board no definite height and
  `fitCell()` collapsed every cell to 1×1px — the board was unusable on
  phones. Guarded in QA.
- Cell interaction: tapping a `.xw-cell` div focuses its paired `<input>`
  (inputs are DOM siblings of the cell divs, not children — the div is the
  tap target). `.active-cell` paints the selected cell; typing advances to
  the next cell. `ResizeObserver` refits on layout change.

## `gallery.html` — photo gallery

- Responsive grid of `figure.gallery-item` thumbnails.
- Tapping a figure opens the viewer `#glViewer` (removes `hidden`);
  `#glvClose` closes it (restores `hidden`); `#glvScrim` dismisses.
- Guarded in QA (GALLERY MOBILE).

## `newsletter.html` — newsletter

- Generated by `scripts/build_newsletter_html.py` from the feed; static
  content page.

## Game pages (`games/*.html`)

22 game files exist: 19 registered in `games/games.json` (deployed) and 3
local-only (gitignored, never deployed — see GAMES.md). Each is a
self-contained single-file game with its engine under
`games/assets/<game>/` where applicable. Full inventory in GAMES.md.
